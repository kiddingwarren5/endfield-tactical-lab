## 启用方式与现状
- 模拟器参数 `timingSource:'akedata'` 时按本表取：战技 / 连携 / 终结技 / 下落的施放时长（busy）、首个命中帧、终结技演出（全队暂停）、主控与非主控的普攻各段。没有数据的干员退回 timing.js 的武器默认表；技能表的普攻段数与解包不一致时也退回（日志里会看到按武器表计算）。
- 默认（不传）仍是 timing.js 的假设表，现有预设、金标准与 107 个旧测试都按默认口径；tests/timing-akedata.test.mjs 锁住解包口径。切换默认值要先更新金标准并过评审。
- 命中时刻：有命中帧的技能用首个命中帧；伤害在生成物（弹道 / 区域实体）里的技能（如汤汤终结技、祀连携）本文件没有记其帧，仍按施放时长的 60%（终结技 80%）估。后续把子实体的帧并进来。
- 解包帧是配置帧，不含攻速、输入延迟、弹道飞行；和实战的差异要靠日志核。
