## 编队与练度
- 管理员 + 陈千语 + 骏卫 + 第四人（黎风 / 艾尔黛拉 / 余烬 / 秋栗可替换）。下面是黎风版本。练度未说明。

## 敌人与模式
- 未指定，分别提到打小怪与打 Boss 的差别。

## 文字轴（按顺序）
1. 开局黎风战技：物理脆弱 + 1 层破防。
2. 陈千语连携触发，再 +1 层破防。
3. 触发管理员连携。
4. 主控重击（普攻最后一击）触发黎风连携，获得连击。
5. 管理员战技引爆破防（猛击）。
6. 触发骏卫连携，回复技力，进入下一轮。

## 作者给出的理由
- 物理队核心：队友叠破防（最多 4 层），由管理员战技猛击引爆。
- 陈千语战技 1 层 + 连携 1 层，是物理队必带。
- 骏卫负责回技力；长轴可算好回技力时机，让管理员吃到碎甲增伤。
- 打小怪 2 层破防够用；打 Boss 需要中间插陈千语战技叠层，或开黎风终结技直接给 2 层。

## 本案例能证明什么
1. 物理队的“叠破防 → 引爆”与寒冷队的“叠附着 → 别礼连携吃层”结构同构，排轴工具可以用同一套“层数资源 + 消耗者”模型。
2. 明确了“Boss 战层数不够时插战技或终结技补层”的分支。

## 本案例不能证明什么
- 版本早（约 2026-02），v1.6 数值和干员（如弭弗）变化后未必最优。
- 无时间点、无技力数字；具体破防层数与是否插陈千语战技要按敌人调整（原帖自述）。
- 实战日志（案例 11）里的顺序是“骏卫终结技 → 黎风战技 → 陈千语连携/战技 → 管理员连携 → 黎风连携 → 黎风终结技 → 骏卫战技碎甲”，与本帖基本一致但多了终结技穿插。
