## 轴（按作者口述顺序整理）
一轮（无大招）：秋栗战技挂灼热 → 莱万汀重击 → 莱万汀连携（腐蚀 → 法术脆弱）→ 秋栗战技再挂一层 → 艾尔黛拉连携 + 秋栗连携 → 狼卫连携挂一层（凑 3 层熔火）→ 莱万汀重击 → 莱万汀强化战技（第一次，之前要有法术脆弱）→ 下一个强化战技直接放。
大招轮：熔火 3 层、腐蚀转脆弱后莱万汀开大，强化战技留到大招期间 / 大招结束前放；秋栗大招给连击 buff 与技力回复。

## 启发式
- 技力是瓶颈：“整个队伍的技力循环非常的长”；秋栗大招回技力是为了缩短循环。
- 挂火主要靠秋栗战技（放两次），狼卫 / 艾尔黛拉连携补层；莱万汀自己的重击与连携负责把腐蚀转成法术脆弱。
- 强化战技的前置：法术脆弱已上、熔火 3 层；大招期间打强化战技吃增伤。
