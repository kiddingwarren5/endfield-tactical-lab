## 轴（按作者口述顺序整理）
无大招：黎风战技 → 黎风战技（补两层）→ 管理员重击 → 陈千语连携 + 黎风连携 + 骏卫连携（三个人的连携，骏卫上碎甲）→ 破防四层 → 管理员战技（结算四层破防）。
有大招：管理员重击 → 三个人的连携 → 等陈千语战技 → 黎风大招（连击 buff）→ 骏卫大招（连击 buff）→ 补 buff → 管理员战技结算。

## 启发式
- 破防层数是这支队的“附着”：黎风战技叠层、骏卫连携上碎甲，凑到 4 层再让主控战技结算。和冰队“叠到 4 层再吃”同构，只是资源换成破防。
- 主控重击一次触发三个人的连携（重击是触发器）。
- 大招提供“连击 buff”，要“补 buff”保持覆盖；结算战技放在 buff 内。
- “等一个小爷子的战技”：明确的等待。

## 未核对
- 精确时刻（有剪辑）；各人潜能；伤害数字（画面上 4224/5564 这类是血量）。
- 处决、重击次数不是可排动作；“结算四层破防”的战技段条件（breach≥4）需要在模拟器里核对是否建模。
