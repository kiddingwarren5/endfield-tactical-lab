## 本案例能证明什么
1. 满潜满精炼寒冷队在该 Boss 上的一条真实路线：全程只有 **2 个“充能节”**，别礼终结技只放 1 次（22.42s），在第 2 节末尾、祀增幅覆盖内释放。
2. 01 号位放的是**诀**而不是别礼。诀连携出现在 3.99 / 17.89 / 23.89s（间隔 13.9s、6.0s）；第二个间隔明显短于第一个，与“祀终结技/连携缩短 01 号位连携冷却”的说法方向一致，但日志没有冷却字段，不能据此算出缩短量。
3. 别礼终结技三段在无暴击时为 1:1:2（案例 03/04 中 171,241 / 171,241 / 342,482 与 202,780 / 202,780 / 405,559），可以用来回归终结技分段倍率比例。
4. 祀终结技增幅数值 43.2%（满潜/满精炼）与持续 14.79s 可直接用于校对数据表。

## 本案例不能证明什么
- 不能证明这是最优轴：只有一条样本，日志不含技力、能量与附着层数，也没有主控信息。
- 别礼连携“第1组 / 第2组命中”（序号 1/2，间隔 1.3s）是同一次连携的两段还是两次连携，日志没有直接标注；本项目 NEXT_STEPS 认为别礼连携分两段，但本场证据不足以证明。
- 满潜满精炼 + 该 Boss 血量与抗性下的 23.962s 不能外推到低练度或其他 Boss。
- 开局资源由模式决定（推测），不能直接套到常规关卡。
