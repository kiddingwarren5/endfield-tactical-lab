## 本案例能证明什么
1. 中等练度（祀潜1、别礼潜4、武器低精炼）+ 攻击药，也能在罗丹上 18.1s 击杀；开局“祀战技 → 祀终结技 + 诀连携同刻 → 诀终结技 → 别礼连携 → 别礼终结技”的顺序与案例 01/02 相同。
2. 01 号位同样是诀。
3. 罗丹这种短战斗里，所有终结技一轮全开，不存在“第二次终结技被放弃”的问题。

## 本案例不能证明什么
- 18s 的短战斗不包含任何循环，无法验证充能轴、技力平衡。
- 攻击药与潜能不同，不能直接和案例 04（同 Boss 18.979s）比较时长差异的来源。
