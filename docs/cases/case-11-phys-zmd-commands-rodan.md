## 本案例能证明什么
1. 物理队在日志中可直接读到**失衡值变化**和“碎甲 / 猛击 / 倒地 / 浮空”等物理异常事件，可以用来回归失衡与物理异常建模（寒冷队日志没有这么细的失衡数据）。
2. 同 Boss 对照：物理队（中低潜）39.8s，寒冷队 18.1–19.0s，灼热队 19.0s；差距主要来自练度与队伍上限，不应解读为机制结论。
3. 管理员猛击在 27.53s 消耗破防造成 262,091，是本场最大单击之一，符合“队友叠破防、管理员战技引爆”的物理队思路（案例 12）。

## 本案例不能证明什么
- 第 160 名、中低练度，不代表物理队上限。
- 破防层数、技力均无字段；“猛击消耗了几层破防”只能从倍率反推，本次未做。
