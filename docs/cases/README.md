## 战斗日志口径（zmdlogs.com）
- 数据取自页面内嵌的 RSC 数据（`battle / roster / timelineEvents / roleSkillStats`），**每份都核对过：逐击伤害合计 = 页面各干员总伤**。
- 时间：`timeSource=game_timer`、`timelineZeroSource=official_timer_start`，即游戏官方计时；技能时间为“首个命中时间”或日志的“释放标记”（无伤害值的事件），不是按键时刻。
- 日志**没有**：技力、终结技能量、附着/破防层数、主控是谁、冷却。所有关于这些量的说法都是推测。
- 榜单格式“X+Y”= 干员潜能 + 武器精炼（由 roster 字段 `characterPotential`、`weaponRefine` 对照得出）。
- 技能等级 12 推测为 9 级 + 专精 3（未确认）。
- 别礼连携在日志中常出现“第 1 组小额命中 + 0.9–4.5s 后第 2 组大额命中”（eventGroupKey 序号 1、2）。是同一次连携的两段还是两次连携，日志没有直接说明，**待视频逐帧核对**。

## 跨案例观察（推导，供批次 5/7 参考，不是结论）
1. **01 号位**：zmdlogs 高名次寒冷队（案例 01–04）都把诀放 01 号位；月咒视频（案例 06）和案例 05 把祀放 1 号位。哪种更好，没有同条件对比。
2. **开局资源因模式而异**：危境再现的日志里终结技在 3–10s 就出现（案例 01–04、10、11），战争回响的案例 05 首个终结技在 63s；唐傀、PigeonXwX 都说战争回响开局 7 技力。排轴工具必须把“初始技力/能量”作为输入，不能固定。
3. **等 4 层 vs 立即连携**：月咒（案例 06）与唐傀（案例 07）都按“每节凑 4 层再让别礼连携吃”；唐傀给出了“为打腐蚀，这一节不让别礼连携吃”的例外。日志中别礼连携的大额命中（29–71 万）都出现在多层附着与多种脆弱叠加之后，但没有层数字段，**无法直接证明 4 层最优**。需要在工具里对两种候选轴做同条件伤害比较。
4. **何时开终结技**：短 Boss（罗丹）四人终结技一轮全开；有阶段转换的 Boss（案例 02）祀终结技用在第一段，别礼终结技留到第二段收尾且不吃增幅；白垩界卫（案例 04）别礼终结技开了两次。说明“周期内第二次有价值的终结技不应放弃”这一原则要按 Boss 阶段与血量判断。
5. **可直接用于回归的数值**（来自日志）：祀终结技增幅 43.2%（潜5精6）/36%（潜1、潜2）；玉中身承伤易伤 21%（精6）/18%（精5）/15%（精3）/12%（精1）；诀寒冷脆弱 18%（潜5、潜4）/11.7%（潜0）；汤汤法术脆弱 10%（潜5）/5%（潜0）；别礼寒冷脆弱 16%（另见 12%）；别礼终结技三段 1:1:2；失衡承伤 +30%。这些数值需要与 dist/ 数据表交叉核对后再写入规则。
6. **资源结算子段**：月咒演示汤汤战技秒接连携会丢失这次战技的终结技充能（案例 08.1），资源模型可能需要区分“附着生效”与“能量结算”时刻。
