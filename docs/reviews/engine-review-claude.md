- **静态计算链**（面板 → 单段 → 分段总伤 → 效果解析）的主体公式与 rules B8/B9/A1–A6 一致，边界截断正确。

- 修复前，模拟器的效果层与静态计算器严重不一致：
  - 修正被乘 N 次；
  - 全队唯一效果叠加；

  - 梨诺战技免费。
  修复后，模拟与静态口径一致。
- **充能阈值**原来因采样口径系统性高估，已改为读取事件日志。
