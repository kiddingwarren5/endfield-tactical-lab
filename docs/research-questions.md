# 终末地战斗机制研究问题清单（供独立研究者使用）

目标游戏：《明日方舟：终末地》（Arknights: Endfield），以当前公测版本（v1.6，2026-10）为准。
要求：每一条结论必须给出来源链接（官方 wiki.skland.com / 华法琳 warfarin.wiki / NGA / B站 / 贴吧 / 米游社类社区研究 / 视频实测），并标注来源类别：官方数据 / 玩家研究 / 实测视频 / 推测。无法确认的写“未确认”，不要编造。中文作答，输出 Markdown。

## A. 伤害公式
1. 单次伤害的完整公式与乘区划分：攻击力、技能倍率、暴击、增伤（伤害加成）、增幅、脆弱、易伤、连击、失衡、防御、抗性、减免、源石技艺强度、异常等级。各乘区内是加算还是乘算？乘区之间是否相乘？
2. 暴击倍率默认是多少？暴击率默认值？是否存在暴击伤害加成属性？
3. 防御公式（例如 100/(100+防御)）及典型敌人防御值；敌人抗性评级（D/C/B/A/S 等）与百分比的对应表；是否存在负抗性。
4. “脆弱”（寒冷脆弱/法术脆弱/物理脆弱等）与“易伤”的区别与归属乘区；“增幅”乘区包含哪些效果（例如祀终结技）；“增伤”乘区包含哪些（装备属性、武器技能等）。
5. 机制伤害：法术爆发、碎冰、燃烧（初始/每秒）、导电、腐蚀、冻结、击飞、倒地、猛击、碎甲 的倍率、与异常等级的关系、是否受等级系数（如 1+89/196）影响、是否吃增伤乘区、是否可暴击、触发者归属。
6. “源石技艺强度”（技艺强度）具体加成哪些伤害。
7. 游戏内部数值是否有取整/截断（面板攻击力、伤害显示）。

## B. 属性与攻击力
8. 面板攻击力公式：角色基础攻击、武器基础攻击、攻击力%、主能力/副能力换算（每点主能力+0.5%？每点副能力+0.2%？）、固定数值攻击力加成的加算位置（装备固定加攻 vs 食物/药剂固定加攻）。
9. 四种能力（力量/敏捷/智识/意志）对各职业的意义；“全能力”“主能力%”属性如何换算。
10. 终结技充能效率：哪些能量来源受它影响（普攻命中、技能、受击、连携）；加算还是乘算；是否有上限。

## C. 资源与技能系统
11. 技力：队伍共享上限（200？），初始技力，普攻每段回复量，各武器类型普攻回复差异，受击/闪避回复。
12. “返还技力”（俗称毒技力/假技力）的机制：消耗这部分技力是否不回复终结技能量，消耗先后顺序；哪些技能返还技力。
13. 终结技能量：普攻、战技、连携技各获得多少，各干员终结技能量上限（例如 240），施放后是否清零，能否溢出；充能效率是否作用于所有来源。
14. 连携技：触发条件（队友施加异常/附着、特定状态）、触发窗口时长、冷却时间、是否能被多人同时触发、主控切换关系。
15. 战技：冷却/技力消耗，多段战技（如可连续施放的战技）的规则。
16. 法术附着：层数上限（4？）、不同属性附着是否互斥/覆盖、附着持续时间、法术爆发触发条件（两种属性附着相遇？达到层数？）、异常等级如何决定。
17. 主控与非主控：非主控干员是否自动普攻？自动普攻是否有伤害衰减、衰减比例、频率；非主控是否回复技力/终结技能量。
18. 普攻攻击串：各武器类型普攻段数、每段倍率结构、重击（蓄力/第四段）判定、下落攻击、处决攻击触发条件（失衡/倒地）。
19. 失衡：失衡值/韧性机制，失衡窗口时长，失衡后伤害加成（“对失衡目标伤害加成”属性、失衡易伤）。

## D. 装备与武器
20. 装备精锻：三条属性各自精锻 0–3 级，精锻数值规律；两条属性装备的处理；精锻是否影响充能效率等百分比属性。
21. 套装效果：2件/3件生效规则；全队不可叠加的套装（例如长息）如何处理；同套装多人携带是否取最高值。
22. 武器潜能与第三技能等级对应（0潜=Rank4，满潜=Rank9？），武器基质（Substrate）对武器技能的影响与最终等级计算。
23. 配件是否可以重复装备同一件。

## E. 食物与药剂
24. 战斗中可用的食物/药剂清单及效果（攻击力固定值/百分比、能力值、充能、技力、伤害加成），持续时间、同类是否互斥/覆盖。

## F. 排轴相关
25. 社区公认的高效循环/排轴原则（技力分配、终结技覆盖、连携叠层）与典型文字轴案例（例如“别礼/汤汤/祀/诀”队），附来源链接。
26. 视频实测中战斗时间的口径（含终结技演出暂停、命中停顿）。
