## A. 伤害公式与乘区

### A1 单段伤害（引擎 damage.js calcSegment）
```
D = ATK × M × Crit × (1+Σ增伤) × (1+Σ增幅) × (1+Σ脆弱) × (1+Σ易伤) × 连击 × 失衡 × Q_def × Q_res × Q_reduction × 等级系数 × 技艺系数
```
- 乘区之间相乘；同一乘区内加算，但先执行效果自身规则（无法叠加/取最高/层数上限）。【研究：灰机 Wiki《伤害》、NagiYume《终末地数据导论》】
- 增伤区包含：装备“X伤害加成”属性、武器“X伤害提升”、“所有技能伤害+”、“战技/连携技/终结技/普通攻击伤害+”、“造成的伤害+”、“对失衡目标伤害+”等；按 applies 条件过滤（属性、技能种类）。【研究】
- 增幅区：原文明确写“增幅”的效果（祀、赛希、梨诺、安塔尔终结技等）。【官方原文 + 研究】
- 脆弱区：原文写“脆弱”的目标减益（寒冷脆弱/法术脆弱/物理脆弱…）；寒冷伤害同时满足寒冷脆弱与法术脆弱的类型条件，是否同时生效取决于各效果自身的叠加限制（当前按同时计入）。【研究；叠加细节待实测】
- 易伤区：原文写“使目标受到的伤害+N%”且未写脆弱/增幅的效果，以及导电（法术易伤）、碎甲（物理易伤）。【研究】
- 等级系数与技艺系数只作用于机制伤害（A5/A6），不作用于普通元素技能直伤。【研究】
- “所有技能伤害”不含普通攻击（解包中 AllSkillDamageIncrease 与 NormalAttackDamageIncrease 为独立字段）。【解包 + 推导】

### A2 暴击
- 基础暴击率 5%，基础暴击伤害 +50%（暴击 ×1.5）。存在暴击伤害属性。【研究：gamekee 机制研究、BWIKI 数值范围；解包 attr 9 = 0.05】
- 界面口径：不暴击 ×1；必暴击 ×(1+暴伤)；暴击期望 ×(1+暴击率×暴伤)。【推导】

### A3 防御、抗性
- Q_def = 100 / (100 + DEF)，DEF≥0。默认对照靶 DEF 100（罗丹、碾骨劫掠者基础值 100）。【研究 + 解包敌人表】
- Q_res = 1 − 抗性%/100；负抗性按同式（−20 → ×1.2），未见“负抗性减半”依据。【研究】
- 评级映射：D=0，C=20（也有 30 仍显示 C 的记录），B=50；A/S **未确认**。界面提供评级与自定义数值并存。【研究；待补敌人原始表】

### A4 增幅/脆弱/易伤/增伤归属表
| 名称 | 典型来源 | 乘区 |
|---|---|---|
| 脆弱 | 寒冷脆弱、法术脆弱、物理脆弱（干员天赋/技能/武器） | 脆弱 |
| 易伤 | 导电法术承伤、碎甲物理承伤、“受到的伤害+” | 易伤 |
| 增幅 | 寒冷增幅/灼热增幅/法术增幅（祀、赛希、梨诺…） | 增幅 |
| 增伤 | 全伤害、元素伤害、技能种类伤害、对失衡目标伤害 | 增伤 |

### A5 机制伤害（引擎 skills.js mechSegments）
n = 触发时消耗的附着/破防层数（1–4）。90 级等级系数：法术 1+(90−1)/196 = 1.45408；物理 1+(90−1)/392 = 1.22704（与解包 attr 49 / 25 的 90 级值一致）。【研究 + 解包】
| 机制 | 基础倍率 | 备注 |
|---|---|---|
| 法术爆发（同属性） | 160% | 不随层数线性增加 |
| 燃烧初始 / 每秒 | 80%(1+n) / 12%(1+n) | 持续伤害不暴击（研究） |
| 导电 / 腐蚀 / 冻结 初始 | 80%(1+n) | 导电附带法术易伤 12/16/20/24% |
| 碎冰 | 120%(1+n) | 研究用法术等级系数 |
| 击飞 / 倒地 | 120% | 物理等级系数 |
| 猛击 | 150%(1+n) | 物理 |
| 碎甲 | 50%(1+n) | 物理易伤 12/16/20/24% |
- 机制伤害按**触发者**攻击力/等级/技艺结算；碎冰归属打碎冻结者。【研究】
- 当前实现沿用上表（与交接 Demo 一致）；v1.6 逐项复测与多人归属顺序**未确认**。

### A6 源石技艺强度
- 乘在法术爆发、法术/物理异常伤害上：×(1+s/100)；不是通用法伤加成。【研究】
- 导电/碎甲/腐蚀的易伤效果：×(1+2s/(s+300))（研究系数；引擎未实现，列为缺口）。

### A7 取整
- 干员属性面板显示 = 内部值向下取整（1224 个样本全部吻合）。【解包 vs 官方，docs/data-sources.md】
- 装备百分比属性显示 = 四舍五入到 1 位小数；源石技艺强度显示向下取整；全伤害减免内部存 1/(1+d)。【解包 vs 官方】
- 伤害跳字取整方式**未确认**；引擎不取整，界面显示四舍五入到整数，并在拆解中注明。

## B. 属性与攻击力（引擎 stats.js）

### B8 面板攻击力
```
ATK = [ (角色基础 + 武器基础) × (1 + Σ攻击力%) + 装备固定攻击 ] × (1 + 0.005×主能力 + 0.002×副能力) + 食药固定攻击
```
- 主能力每点 +0.5%、副能力每点 +0.2% 攻击：【研究（NagiYume）】；交接 Demo 的截图回归（6368 / 6519）与此式一致【实测】。
- 装备固定攻击的位置（攻击%之后、能力乘算之前）来自研究简化式；底层存在多级修饰阶段，**未完全确认**。
- 食药固定攻击：主副能力乘算完成后再加。【实测（用户）】
- 面板攻击显示向下取整。【实测回归】

### B9 四能力
- 各能力 = 向下取整[(90 级基础 + 能力值天赋 + 潜能/武器/装备固定值) × (1 + Σ该能力%)]。主能力%、全能力% 先改变能力值再进攻击换算。【研究 + 实测回归（772/798）】
- 力量 +5 生命/点；敏捷 → 物理抗性，智识 → 法术抗性（100−100/(1+0.001x)）；意志 +0.1% 受治疗/点。【研究】

### B10 终结技充能效率
- 可加成能量来源：ΔU = ΔU基础 × (1 + Σ充能效率)。【研究】
- 不是所有来源都吃效率（管理员特定潜能结晶回能“无法被加成”）；硬上限**未确认**。【官方原文 + 研究】
- 当前引擎：充能效率 = 装备（含逐条精锻）+ 武器 + 套装 + 食药 加算（stats.chargeEff）；按来源区分在批次 7 实现。

## C. 资源与技能系统（批次 5–7 使用）

### C11 技力
- 队伍共享技力**上限 300**，脱战稳定值 200（界面默认初始 200）。【研究】
- 自然恢复约 8 点/秒；主控重击回技力按干员区分（样本：管理员 20、狼卫 18、佩丽卡 15、黎风 21、别礼 30）；精准闪避约 7.5。【研究，v1.6 全干员表未确认】

### C12 返还技力（毒技力）
- 返还部分优先消耗；消耗返还部分不产生“消耗技力→全队终结技能量”收益。【研究（巴哈测试）】
- 已核返还来源：别礼战技 30（潜能1 +5）、管理员潜能1 50、昼雪潜能5 10、卡契尔潜能5 10、汤汤/诀部分技能。【官方原文】

### C13 终结技能量
- 施放战技：全队获得能量（基准：消耗 100 真实技力 → 全队各 6.5 基础）；施放连携技：施放者获得（多数 10，弧光 5、梨诺 20、别礼 40+15n…）；施放终结技消耗全部能量；部分强化状态期间不能获得能量。【官方教学 + 研究】
- 别礼只从自身战技、连携技获得能量。【官方原文】
- 各干员所需能量见 dist/data/operators.js skills.ultimate.params.energyCost。
- 溢出储存**未确认**；模拟器不提供隐藏溢出。

### C14 连携技
- 触发条件按干员定义；冷却、触发窗口（早期资料约 5 秒）、状态持续三者独立计时。【官方原文 + 研究】
- “01 号位”与“主控”不同（祀的部分效果读取 01 号位）。【官方原文】

### C15 战技
- 普通战技消耗 100 技力；替换型战技逐段读取消耗（祀：100 → 起墨 15 → 收笔 0）。【官方原文】

### C16 法术附着与异常
- 常规附着上限 4 层；同属性再施加 → 法术爆发（不需 4 层）；不同属性 → 由后施加属性决定异常（灼热→燃烧、电磁→导电、寒冷→冻结、自然→腐蚀），消耗原附着；异常等级 = 消耗层数（≤4）。【官方教学】
- 附着自然消退时间**未确认**。

### C17 主控与非主控
- 非主控干员会自动普攻（官方更新说明可证）；是否衰减、比例、频率、是否完整攻击串**未确认**。排轴模拟必须把非主控普攻的伤害与资源贡献作为带区间的估计量，不能默认 100%。【官方 + 研究缺口】
- 非主控仍获得战技全队回能与自身连携回能；别礼限制仍适用。

### C18 普攻串
- 段数由干员决定（3–5 段）；重击通常是攻击串末段；空中普攻 = 下落攻击；失衡目标附近普攻 = 处决。【官方原文】
- 逐命中拆分（多弹、多斩）需要解包 blackboard（atk_scale1/2…）或实测，当前按官方段倍率。

### C19 失衡
- 失衡承伤倍率研究常用 1.3；“对失衡目标伤害+”为角色条件增伤，分开处理。【研究】
- 失衡阈值、窗口为敌人参数；默认对照靶永不失衡。【继承要求】

## D. 装备与武器

### D20 精锻
- 每条可精锻属性独立 0–3 级，值 = floor/精确(原始 × 1, 1.1, 1.2, 1.3)；整数属性向下取整；百分比保留内部小数。【解包（1581 值全部吻合）】
- 两条属性装备只有两条精锻项。【官方 + 解包】

### D21 套装
- 3 件激活（无“2 件小效果”）。【官方原文】
- 长息“使其他队友造成的伤害+16%，该效果无法叠加”：同队多人携带不相加；是否取最高/刷新**未确认**（引擎按只计一次、取最高）。【官方原文 + 假设】
- 拓荒“全队造成的伤害+16%，无法叠加”同理。

### D22 武器潜能与基质
- 第三技能等级 = 1 + 潜能(0–5) + 匹配基质加级(0–3)；前两条 = 培养 3 + 匹配基质加级(0–6)。继承规则“0 潜 = Rank4，满潜 = Rank9”对应基质 +3 的默认；界面保留潜能↔Rank 联动，基质默认满（9/9/4）。【研究（gamersky 基质详解、BWIKI 联结点表）】

### D23 配件重复
- 两个配件槽可装备同名配件的两个实例（实战记录：汤汤双碾骨面具·贰型）。【研究/实战记录】→ 界面允许同名配件重复。

## E. 食药
- 300 秒增益；清单见 dist/data/consumables.js（25 项与输出相关）。固定攻击食物（清炖兽排参须汤 +180 攻击 +11% 暴击）采用官方 wiki 当前值（旧 BWIKI 为 +200/+13%，已过时）。【官方】
- 同类互斥/覆盖**未确认**；界面按勾选全部计入并标注。

## F. 排轴相关（批次 5 详述）
- 真实技力与返还技力分别记账；避免技力溢出；把主伤害放进增幅/脆弱/易伤/失衡重叠窗口；连携窗口与冷却；01 号位/主控/伤害归属分别记录。【研究】
- 终结技演出会暂停部分效果计时（莱万汀官方说明）；技力自然恢复在演出期间暂停（研究）；视频计时需区分录像时间/关卡计时/日志时间/效果计时。
