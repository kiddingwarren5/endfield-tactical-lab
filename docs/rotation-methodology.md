# 排轴方法论

这份文档回答三件事：玩家在现实里是怎么排轴的（启发式）；我们的自动排轴怎么对应这些启发式、哪些由搜索自己得出、哪些还没覆盖；改动排轴算法时按什么流程验证，避免无方法论地改来改去。

## 1. 玩家排轴的启发式（从案例里归纳）

来源：案例 06（YZ-月咒 祀别汤诀，视频字幕）、案例 19（YZ-月咒 伊汤赛洁，视频画面逐帧）、案例 18 里的九条文字轴（GameKee / 巴哈 / TapTap / B 站评论，可信度低一档）。每条标注出处，没有出处的不写。

### 1.1 结构：充能节 × N + 爆发节
- 轴分“充能轴”和“爆发轴”两种节，爆发节是四人终结技连开，充能节是把能量和附着准备好。案例 06 是三充一爆；案例 19 是先爆发再充能循环（危境再现 Boss 开局能量满）。
- 每节的动作集合基本固定，差别只在终结技是否放、连携冷却是否转好（案例 19 作者原话：“区别是汤汤的连携刚才用过了”）。

### 1.2 启动门槛：技力
- 每节启动前先攒技力：“永远要保证自己两格多一点技力”，不够就靠闪避和自然回复等（案例 19）。一格 = 100 技力 = 一次战技。
- 启动顺序是辅助先放战技（赛希 / 祀），再由主控叠附着、重击触发连携（案例 06、19 一致）。

### 1.3 附着与连携：叠层、触发、吃层
- 叠到目标层数再让吃层的人放连携：案例 06 每节凑 4 层再让别礼连携吃；短战场景不等第 4 层（案例 06 的危境再现变体）。
- 连携“亮了就按”，不留（案例 19：“这个时候同时会触发三个人连携”“亮了直接摁”）。例外是案例 06 的诀连携要放在重击之后，因为冷却 18 秒要留给下一节。
- 主控重击是触发器：伊冯天赋瞬发重击、别礼战技后重击幻影追击，都是“战技 → 重击 → 触发连携”的链。

### 1.4 终结技：固定顺序 + 两处对齐
- 顺序固定成记号（案例 19 的“1342”；案例 06 的祀 → 诀 → 汤汤 → 别礼），增幅 / 脆弱先开，吃增益的大招最后开。
- 对齐只有两种：演出衔接（“等伊冯转身再开洁哥大招”）和效果对齐（“洁哥大招 2 秒后再开汤汤大招”，定身与巨浪对齐）。其余都是尽早放。

### 1.5 记录型机制
- 祀笔意：河山共影开记录 → 整节在记录内 → 收笔结算；收笔放在节尾、转阶段前（案例 06）。这是唯一一个“为了结算而刻意安排顺序”的机制。

### 1.6 火队的启发式（案例 20，巴晓白 莱狼秋羊，视频逐帧）
- 技力是瓶颈：“整个队伍的技力循环非常的长”，所以带秋栗，靠秋栗大招回技力缩短循环；这是“选辅助先看资源”的例子。
- 层数来源分工：挂火主要靠秋栗战技（一轮放两次），狼卫 / 艾尔黛拉连携补层，凑 3 层熔火；主控自己的重击和连携负责把腐蚀转成法术脆弱。
- 强化战技有前置：法术脆弱已上、熔火 3 层；大招期间再放吃增伤，“留到大招结束”。这是“动作有前置条件链，顺序由链决定”的例子，和冰队的“叠层 → 吃层”同构。

### 1.7 资源计数驱动的轴（案例 21，春风满马 提弗洛斯自然队，视频逐帧）
- 下一步由资源数决定：进本 4 启示、攒到 8 启示、大招补附着补回 8 启示、翔龙 14 箭。和电队“雷枪数 / 剑数”同类，都是“资源到阈值再放”。
- 等冷却是明确动作：“等诀连携 CD 好后”启动循环，“拖提弗连携 CD”。这是“刻意延迟”的直接证据，第二段时刻精调要能表达。
- 开场 / 循环 / 爆发三段结构，和冰队“充能 × N + 爆发”同构；作者也说“充能轴真的很长”。

### 1.8 物理队：破防层数就是附着（案例 22，巴晓白 管理员物理队，视频逐帧）
- 黎风战技叠破防、骏卫连携上碎甲，凑到 4 层再让主控战技“结算四层破防”；和冰队“叠 4 层再吃”同构，资源换成破防层。
- 主控重击一次触发三个人的连携；“等一个陈千语的战技”是明确等待；大招给“连击 buff”，要“补 buff”保持覆盖，结算战技放在 buff 内。

### 1.9 文字轴里的其他说法（可信度低，待视频核对）
- “技力卡死就打不出强化战技”“续笔意时技力爆了”（破碎的★ 祀卡轴简介）：技力是火队的瓶颈。
- 物理队按“碎甲 / 猛击 → 处决”分段（管理员物理队）；电队按“雷枪数 / 剑数”分段（艾维文娜、庄方宜）。这些段的触发条件现在只在 note 里，没进模拟。

## 2. 这些启发式在自动排轴里的位置

| 启发式 | 现在怎么对应 | 状态 |
|---|---|---|
| 充能节 / 爆发节结构 | 不手写。固定窗口内的保底伤害当目标，终结技连开与否由分数决定；页面上的分节只是事后按终结技簇切出来的 | 由搜索得出 |
| 技力门槛 ≥ 两格 | 不手写。模拟器里技力不够战技就放不出，最早可行解码天然等到够；但“攒到两格再启动一整节”这种预留没有表达 | 部分 |
| 辅助先放战技、主控叠层、重击触发 | 不手写。触发链在数据里（连携条件、重击附着），搜索里顺序对了就触发 | 由搜索得出 |
| 叠到 N 层再吃 | 顺序表示里用“等附着层数”动作（WAIT_ACTS），当前流程不启用；显式时刻精调能把吃层动作往后挪 | 部分 |
| 连携亮了就按 | 最早可行解码就是这个规则 | 对应 |
| 终结技顺序与两处对齐 | 顺序由退火搜出；“2 秒后”这类对齐靠第二段时刻精调（±0.1–2 秒挪动） | 对应 |
| 笔意收笔放节尾 | 不手写。收笔是战技阶段之一，搜索决定 | 由搜索得出 |
| 碎甲 / 处决 / 雷枪 / 剑数分段 | 处决、重击次数不是可排动作；雷枪与剑数已是资源规则 | 部分 |

原则：启发式只用来做三件事——生成搜索的起点、解释结果、设计对照实验；不把启发式写成硬规则（项目约定：不按角色名写特殊规则、不为了对上视频硬加约束）。

## 3. 当前算法（2026-10-30）

1. 束搜索热启动：按时间每秒一步，每步试所有可放动作或不动，留最好的 6 条；给第一段一个起点。
2. 第一段（80% 预算）：顺序表示 + 最早可行解码的模拟退火。顺序表示就是“连携亮了就按、能放就放”的启发式，所以它找的是结构：谁先谁后、放几次。
3. 第二段（20% 预算）：以第一段的实际时刻为起点，各成员独立时间线，逐动作由粗到细挪时刻、只接受改进。它找的是对齐：终结技相隔几秒、吃层等不等、收笔放哪。
4. 候选：第二段最优、精英、第一段结果，去重后前 4，按无修复重放的保底每秒排序。

不做的：等待动作当普通动作搜（稀释预算）、多起点退火（留出验证没泛化）、带插删破坏的时刻搜索（一半候选非法）。依据在 docs/reviews/planner-benchmark.md。

## 4. 改算法的流程

1. 先写问题，不带倾向地给独立评审（docs/reviews/planner-ideas-gpt.md、planner-review-gpt-2.md），把它指出的错误先修、加回归测试。
2. 任何改动先在案例 06 编队上做“同一检查点分叉”实验（同起点、同剩余预算），只比它是否优于继续原算法。
3. 过了再做留出验证：至少 4 支机制不同的编队 × 3 种窗口 × 同预算，参数不再调；12 组里多数不差才采用。
4. 标答对照只用视频逐帧转写的轴（案例 06、19），文字轴只做结构参考；对照口径是同窗口、同配装、同开局能量的保底每秒。
5. 每次改动把结果写进 planner-benchmark.md，HANDOFF 只写结论。

## 4.1 标答对照怎么用（案例 19 的例子）

对照的目的不是比大小，是找根因。案例 19（伊汤赛洁，视频逐帧）30 秒窗口：标答 33,854 每秒，自动 52,038。拆开看：
- 自动轴从不放伊冯终结技，30 秒里放了六次汤汤战技。查数据：伊冯终结技三段里只有 20% 那段在算，300% 的末尾重击和冻结目标 600% 的追加都标为未建模，所以模拟里它只打 1k。这是模拟器缺口，不是玩家排错。修法是通用机制“终结技期间普攻强化 + 结束时追加一击”，不按角色名写。
- 标答编码规则：作者说连携“亮了就按”，序列里每个连携要紧跟它的触发动作；按口述顺序排会错过 5 秒窗口（第一版编码跳过 7 步，改后 3 步）。
- 视频里 6 个动作用了 25 秒，模拟里 7 秒：人手慢、要躲 Boss、有剪辑。标答时间线不能直接当时刻真值，只当顺序真值。

规则：比值明显偏离 100% 时，先查“自动轴多做了什么 / 少做了什么”，再查对应的数据段是否建模；只有两边都对上了，比值才有意义。

案例 20 / 22 的编码教训：标答序列要按触发链排，不按作者口述先后。火队是 秋栗挂火 → 主控重击吸收灼热（目标回到无附着）→ 艾尔黛拉连携（强制腐蚀）→ 莱万汀连携；物理队是 黎风叠破防 → 管理员战技猛击消耗破防 → 骏卫连携碎甲。按口述顺序排会卡住 30 秒再跳过。另外非寒冷队的终结技能量在模拟里远充不满（验证清单 50），所以这两支的比值暂时也无效。

## 5. 还没覆盖的

- 技力预留（“攒到两格再启动”）：没有表达方式，搜索只会尽早放。要验证它是否真的更优，需要在案例 19 编队上把“节首等技力”加进第二段候选再比。
- 处决、重击次数、切主控：不是可排动作，物理队的轴对不上。
- 提弗洛斯的空中普攻 / 启示计数未建模（案例 21），自然队的标答对照暂不可信。
- 开局能量：危境再现 Boss 按开局满处理（案例 19 假设），常规关按 0；视频里能量条没逐帧读过。
- 开局能量：案例 19 是危境再现 Boss，按开局满处理后终结技时刻与视频顺序一致；若从 0 能量开始，模拟里一整节后伊冯只有 20/220，能量增益模型是否偏低要另找常规关视频核对。
- 终结技“普攻强化”类机制（伊冯冷冻射手等）未建模，自动轴会系统性低估这类角色的终结技。
