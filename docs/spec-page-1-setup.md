# 第一页 · 配置 — 页面规范

一句话：玩家在这一页把“谁、怎么练、怎么装、打什么”填完，按完成就去看轴。所有输入只在这一页，后两页只读。

## 1. 流程

编队（选人 → 点卡片改练度/武器/装备/食药）→ 目标（场景、时长、敌人）→ 完成。
完成后跳到排轴页并立刻开始计算；回来改任何一项，排轴页重新算。

## 2. 编队区

四个号位横排，号位顺序就是队伍顺序（01 号位有实际意义，例如祀终结技减 01 号位连携冷却）。

空位：
- 一个“添加干员”选择器，已在队里的不出现；官方数据未公开的干员灰掉并标“官方数据未公开”。
- 选中即入队，并自动套默认配装；队里还没主控时这人就是主控。

已有干员的卡片（只读摘要，点击展开编辑区）：
- 号位、★主控标记、头像、名字。
- 一行：职业 · 元素 · 潜能（有技能形态的再加形态）。
- 一行武器名，一行套装摘要（“潮涌 3 + 生物辅助 1”）。
- 右上角状态标签：默认配装 / 已自定义 / 未配装。
- 卡片顶边用元素色。

同时只展开一个编辑区，位置在四张卡片下方，带指向该卡片的缺口。

方案行（编队标题右侧）：保存当前（可命名，同名覆盖）、载入已存方案、删除当前载入的方案、示例编队（诀 · 别礼 · 汤汤 · 祀）。

新增：编辑区里加“左移 / 右移”，不用先移出再加回来换号位。

## 3. 编辑区（每位干员）

左列：练度、武器、食物与药剂；右列：装备；底部一行面板读数。

练度：潜能 0–5；技能形态（有形态分支的干员才显示：按面板自动 / 各形态）；普攻、战技、连携技、终结技等级 Rank 1–9、专精 1–3。
武器：同武器类型的武器按星级排序；武器潜能 0–5；被动等级；两个词条的基质加级 +0–+6；下面一行显示当前等级的被动文字。
装备：护甲、护手、配件 1、配件 2；按套装排序；两个配件不能选同一件；每件每条属性可改精锻 +0–+3 并显示当前值；下方列出每个套装 n / 3 件、是否生效。
食物与药剂：已选的做成可删的标签；添加；“全队同样”一键复制到全队。
面板读数：面板攻击、主属性 / 副属性、暴击率 / 暴击伤害、充能效率。只读，让玩家对一眼游戏里的面板。
动作：设为主控、恢复默认配装（只在改过之后出现）、左移、右移、移出编队、收起。

新入队的默认练度：潜 0、四个技能专精 3、武器潜 0、词条基质 +6 / +6、精锻全 +3。改过的配装标“已自定义”，不再被默认覆盖。

## 4. 默认配装

规则：装备不填就用默认配装，页面上不出现裸装数字。
每个干员可以有几套方案，不一刀切：输出型（C 位常用套装）、支队主属性 + 附加技能型、充能型（辅助按属性和充能阈值分开写）、第四件常见的生物辅助护板；武器同样给主推和备选。
入队默认用第一套；编辑区里“配装方案”可切换；改过任何一件武器或装备就变成“自定义”，再选一个方案会整套覆盖回去。
方案来自社区标配（B 站、森空岛攻略、NGA 等），每套都带来源，记进 docs/cases；数据在 dist/data/builds.js（方案名、武器、四件、一句话原因、来源）。
没有社区方案的干员走通用规则（engine/defaultBuild.js：按知识图谱里这名干员能触发的套装效果选套装，按主副属性和元素词条选件，同类型最高星且词条对得上的武器），方案名显示“通用规则”，卡片标签仍是“默认配装”。

## 5. 目标区

场景选项卡：常规 · 对照靶 / 短战 Boss（罗丹 / 阿莱克琉斯）/ 阶段转换 Boss / 可失衡 Boss（白垩界卫）。
选项卡下只列这个场景和其他场景不同的事实，每条都影响轴：
- 对照靶：开局没有终结技能量。
- 短战 Boss：开局四人终结技满；限时 25 秒。
- 阶段转换 Boss：开局终结技满；12 到 31 秒无敌。
- 可失衡 Boss：开局终结技满；失衡后 11 秒内多受 30% 伤害。
删掉现在的建议句（“先充能，再集中爆发”“无限血木桩”），那是结论不是输入。

字段：
- 总计战斗时间：20–180 秒，默认 60。限时场景下这个字段换成“限时 25 秒”。
- 敌人防御力：默认 100。
- 敌人攻击间隔不在页面上，固定用默认 4 秒（重装的反击、立盾连携靠它触发）。
- 敌人抗性：物理 / 寒冷 / 灼热 / 电磁 / 自然，每项 D 0% / C 20% / B 50% / 自定义（-100–100）。
- 抗性和防御恢复默认。

## 6. 完成

至少一名干员才可按；按下跳到排轴页。
有人“未配装”时按钮旁提示“N 人未配装，按裸装计算”，不拦。
恢复默认（页眉）：回到示例编队和默认目标，不清除已存方案。

## 7. 页面上不出现的东西

计算方法、候选轴、伤害数字（面板读数除外）、数据来源、版本号、文件路径、摘要条。
时间统一到 0.1 秒，面板数字取整，百分比一位小数。

## 8. 视觉

沿用现有身份：白底、金色标题线、等高线页眉、卡片顶边元素色、章节编号 01 / 02（编队和目标确实是先后顺序）。
窄屏：四张卡片两列再一列；编辑区两列变一列；抗性网格自动换列；页面不横向滚动，侧边留 16px。
键盘可达：卡片是按钮，选择器可用方向键；减少动画偏好下不做过渡。

## 9. 这一页写入的状态（给排轴页和伤害归因页读）

- team[4]：operatorId、potential、skillRanks{normal,skill,combo,ultimate}、mode、weapon{id,potential,substrate,ranks}、gear{armor,gloves,kit1,kit2 各 {id,refine[3]}}、consumables[]、buildSource。
- mainControl：号位下标。
- rot.scenario；rot.enemy{defence,resistances,custom,attackInterval}；rot.auto.horizon。
- savedTeams[]。
